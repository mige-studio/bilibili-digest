## 首批必须通过

1. 打开普通单 P 视频，侧栏只绑定当前视频，能读取标题、作者、简介和公开互动数据。
2. 打开多 P 视频，P1 与 P2 形成独立资料；切换分 P 后不沿用上一段音轨、逐字稿、说话人或笔记。
3. 一条含两人对话的短视频只提交一次整段音轨，返回连续逐字稿与“说话人 1／2”；用户可分别回听并填写姓名。
4. 点击时间点能定位原播放器；跟随播放、当前原话、全文搜索均使用当前逐字稿。
5. 拖选原话后可以解释、复制、保存笔记；概览只能基于完整逐字稿生成，引用必须能回到原话。
6. 我的资料可找回当前视频，并将完整资料、逐字稿、概览、笔记与无 Key 备份保存到用户选择的目录。
7. 刷新、关闭侧栏或查询状态不重复提交付费任务；不确定结果只查询原任务。

## 验收分层

- 自动检查：证明数据边界、页面绑定、任务状态和导出格式没有明显回归。
- 隔离页面检查：证明侧栏真实渲染、按钮可找到、正常与失败状态可理解。
- 真实服务短样：证明公开音轨能完整准备并只提交一次，返回时间点和说话人字段。
- 用户听辨：由使用者抽听说话人 1／2、原话准确性和回听定位；这是首批可用的最终依据。
