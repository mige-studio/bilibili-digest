# B站精读

把电脑端 B 站当前公开视频或当前分 P，变成带时间点与“说话人 1／2”的可搜索逐字稿，并支持画线解释、内容概览、原话笔记和本机资料保存。

当前为 `0.1.0` 本机候选版，尚未发布，也尚未经过用户真实视频听辨验收。

## 首批能力

- 只处理当前打开的公开普通视频；多 P 视频每个分 P 独立读取、转写和保存。
- 将当前分 P 的完整音轨交给火山语音录音文件识别 2.0，统一返回文字、句级时间与本期说话人编号。
- 在逐字稿中搜索、按时间回听、跟随播放，并把说话人编号对应为本期姓名。
- 拖选原话后解释、复制或记笔记，也可保存当前播放点附近的原话。
- 根据完整逐字稿生成分章概览和有出处的关键观点。
- 在“我的资料”中找回视频、逐字稿、概览和笔记，并保存到用户选择的本机文件夹。

说话人编号是本期声音分组，不是人脸识别，也不是跨视频固定身份。声音相近、重叠或音质较差时可能分错，重要引用应点击时间点回听。

## 当前不处理

直播、番剧或影视会员内容、充电专属、私密或受限视频、互动视频、移动端页面，以及整套合集自动批量转写，均不在首批范围内。单个分 P 的处理上限为 5 小时。

## 本机安装与候选检查

1. 在 Chrome 扩展管理页选择“加载已解压的扩展程序”，选择本项目根目录。
2. 打开扩展设置，由使用者本人填写火山语音 Key；如需概览和解释，再填写火山方舟 Key。
3. 分别允许读取 B 站公开音轨、连接火山语音和火山方舟。Key 只保存在本扩展自己的 Chrome 本地空间。
4. 打开一条电脑端 B 站普通视频，点击页面右下角“B站精读”。

```bash
npm install
npm test
```

自动检查不等于真实可用。代码候选完成后，仍需在 Chrome 重新加载扩展，用一条短对话视频验证：当前分 P、整段音轨、说话人 1／2、逐句回听、画线、概览、笔记和本机保存。

## 数据去向

- B 站公开页面接口：只读取当前视频的标题、作者、简介、分 P、公开互动数据和当前音轨地址。
- 火山语音：仅在使用者点击生成逐字稿后，接收当前分 P 的完整音轨。
- 火山方舟 DeepSeek 接入点：仅在使用者生成概览或解释选段时，接收对应文字。
- Chrome 本地空间：保存本扩展的设置、逐字稿、概览和笔记。
- 用户选择的本机目录：只有点击保存后才写入资料文件。

项目没有自建账号、统计服务或中转服务器，也不会导出 B 站 Cookie、读取其他扩展配置或批量采集站内内容。
